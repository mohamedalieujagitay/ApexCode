Features

Everything you need to maintain your coding identity

AI Detection

Local inference using RoBERTa-based models with cloud fallback. Detect watermarks, uniform commenting, and emoji overuse.

Code Humanization

Repository-aware style learning from your commit history. Transform variable names, comments, and code structure to match your style.

Temporal Obfuscation

Jitter engine with delayed staging buffer to simulate organic development pace and avoid commit-frequency fingerprinting.

Stealth Scoring

Real-time per-file stealth score with pattern-based breakdown of detected AI signatures and threshold-configurable alerting.

TUI Dashboard

Terminal UI for live stealth score monitoring with detection heatmap per file and style profile visualization.

Undercover Mode

Commit message transformation and code comment rewriting with adversarial stylometry to bypass AI-detection filters.
