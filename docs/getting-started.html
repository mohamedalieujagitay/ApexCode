Getting Started

Get up and running with ApexCode in minutes.

Installation

One-Click Installer (Recommended)

curl -sSL https://mohamedalieujagitay.github.io/ApexCode/install.sh | bash

From crates.io

cargo install apexcode

From Source

git clone https://github.com/mohamedalieujagitay/ApexCode.git cd apexcode cargo build --release cargo install --path crates/cli
Requirements: Rust 1.70 or later, Git 2.0 or later

Quick Start

Step 1: Go to your project

cd your-project

Step 2: Stage your files

git add your-files

Step 3: Check your code

apexcode

This will show your stealth score and suggest what to do next.

Step 4: Fix AI patterns

apexcode fix

That's it! Your code is now humanized.

Basic Commands

apexcode

Check status and get suggestions. This is the default command - just run apexcode to see your stealth score.

apexcode fix

Auto-fix AI patterns in staged files. This is the main command you'll use to humanize your code.

apexcode scan

See what AI patterns are detected in your files without making changes.

apexcode score

Check your stealth score with detailed breakdown of detected patterns.

apexcode dashboard

Launch the visual TUI dashboard for real-time monitoring.

apexcode config

View or change ApexCode settings.

apexcode install

Install IDE integration for Claude Code, Cursor, Windsurf, or Antigravity.

Typical Workflow

1

Stage your files

git add your-files

Check what's detected

Fix AI patterns

4

Commit

git commit -m "your message"

Advanced Options

Fix specific files

apexcode fix --files src/main.rs

See what would change without applying

apexcode fix --dry-run

Detailed score breakdown

apexcode score --detailed

Reset settings to defaults

apexcode config --reset

Install IDE integration

apexcode install --ide claude apexcode install --ide all
